A travel poster for **Thalorne**, a fictional lantern-lit cliffside harbour town under a huge low moon, with its tall lantern tower, warm windows, and boats on a moonlit sea. The program draws the whole poster procedurally in pure Python (standard library only) and writes a 1024x1024 PNG.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
